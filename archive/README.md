# Archive

Material from earlier stages of the project that the final paper does not use. It is
kept for reference and is not maintained.

`corpus_analysis_2026-04/` holds analyses run on the corpus in April 2026, before the
final dataset: a permutation test for cross-source overlap, source overlap matrices,
coverage by subset, a documentation-gap table and a reproducibility checklist. The
scripts that produced these files are no longer in the repository, and the numbers
predate the released dataset.
