# Configs

| Path | What it is |
|---|---|
| `default.yaml` | The sources of the leaderboard subset, the coverage fields and the main paths, written down in one place. The scripts do not read it |
| `experiment/harness_version_e3.yaml` | Settings of Exp3 (harness version) |
| `experiment/quantisation_e4.yaml` | Settings of a quantisation experiment that was started and is not in the paper |
| `papers/general_llm_papers.txt` | The arXiv papers the extraction reads; `..._batch1.txt` to `..._batch9.txt` are the same list in parts |
| `papers/audit_pdf_ids.txt`, `papers/pdf_cache_ids.txt` | arXiv ids of papers whose PDFs were kept locally. The PDFs are not in the repository |
