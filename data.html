Build the site from the datastore

The site is static. Its registry pages are generated from a folder of EEE files, so pointing the build at the full datastore is all it takes to list every record.

python tools/fetch_datastore.py          # copies Psychias/EvalSpec_Dataset into datastore_cache/
python source/build.py --datastore datastore_cache
python -m unittest discover -s tests     # optional: check the build

Without --datastore, the build reads the sample in datastore/. The name and address of the datastore are set once, in config.json:

"datastore": {
  "name": "EvalSpec",
  "hf_repo": "Psychias/EvalSpec_Dataset",
  "revision": "main",
  "data_dir": "data"
}

When the dataset is renamed on Hugging Face, change hf_repo and rebuild. Every link and every command on the site follows it.

What a datastore record looks like
