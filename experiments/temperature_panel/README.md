# Temperature panel

Paper: Appendix M.7. Four models at temperatures 0.0, 0.7 and 1.0, two samples each, on
GSM8K and on MT-Bench answers scored by a fixed judge.

    python experiments/temperature_panel/run_temperature_panel.py

Needs `OPENROUTER_API_KEY`. Summary statistics are in `temperature_panel_stats.json`.
